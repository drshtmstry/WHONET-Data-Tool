🔧 Bulk Data Corrections
Apply standardized quality fixes across all database records
SPEC_NUM → Uppercase
Normalize all specimen numbers to uppercase to prevent case-sensitive duplicate mismatches.
UPDATE Isolates SET SPEC_NUM = UPPER(SPEC_NUM)
PATIENT_ID → Uppercase
Normalize Patient IDs to uppercase for consistent lookups and deduplication.
UPDATE Isolates SET PATIENT_ID = UPPER(PATIENT_ID)
Trim Whitespace
Remove leading and trailing spaces from SPEC_NUM, PATIENT_ID, FULL_NAME, WARD, and DEPARTMENT.
UPDATE Isolates SET field = TRIM(field)
ORGANISM → Lowercase
Standardize organism codes to lowercase as used in official WHONET code lists.
UPDATE Isolates SET ORGANISM = LOWER(ORGANISM)

ℹ️ Instructions for Sentinel Site Reporting (SAPCAR-Gujarat):
  • Submission Timeline: Format is requested to be filled and shared with the State by the 5th of every following month.
  • Data Integrity: No column is to be left blank; enter 0 only where actual zero.
  • Positive Sample Definition: No growth / normal commensals are defined as:
    • Blood: xxx (no growth), xpa, xep, xsg, nor (normal flora), or scn (CoNS/skin contaminant).
    • Other Sample Types: xxx, xpa, xep, xsg, nor, ora, or vag.
    All other pathogens are identified and counted as positive growth.
  • Specimen Grouping: Blood (bl), Pus (ps), Sputum (sp), Urine (ur), and Others (fluids, aspirates, swabs, tissues).

Welcome to the WHONET Laboratory Database Utility.
🛡️ Safety, Privacy & Verification:
  • Zero Server Upload: Operates locally inside your browser; no patient or laboratory data is sent to any remote server.
  • Data Quality Dependent: Generated surveillance counts and metrics depend strictly on the entry quality and standardized coding of your WHONET data.
  • Manual Verification: Always verify all figures manually before submitting to any surveillance authority or reporting program.
